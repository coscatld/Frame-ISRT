# Reproducibility Manifest

Canonical locations inside this repository for reproducing every number in the
paper. Raw datasets, frozen preprocessing arrays, and trained checkpoints are
**not** redistributed; their fingerprints and the scripts that consume them are.

## Environment

- Python 3.10.20, PyTorch 2.2.0 (CUDA 11.8), NumPy, SciPy, Matplotlib, PyYAML.
  The Mamba backbone comparison used `mamba_ssm 2.1.0`; `ultralytics 8.4.48`
  appears only in auxiliary scripts and is not needed for the Frame track.
- GPU for all reported runs: NVIDIA RTX 4060 Laptop (8 GB).
- `requirements.txt` lists the core dependencies. The full frozen environment
  is not redistributed but was a pinned conda env (`paper_yolo`).

## Frozen Table 1 (Frame track: GRU/Transformer/Mamba and ISR variants)

- Cell picker + preferred-source selection: `scripts/frozen_matrix.py`.
  It scans a developer results archive (set `FRAME_ISRT_FROZEN_ROOT` to its
  path) and enforces per-protocol `protocol_sha256`; it is the provenance
  source for the frozen Table 1 seeds 42/123/2026.
- The picked cells are materialized in `results/per_seed_results_frozen_table1.txt`
  and folded into `results/per_seed_frame.csv` (which also carries the
  extension seeds 2027/2028 and all four control arms).
- Every `result.json` produced by `scripts/train_evaluate.py` records
  `config_sha256`, `protocol_sha256`, `checkpoint_sha256`, `git_head`, and the
  environment.

## Cluster-aware pooled statistics (external review Item 1)

The 60 §4.5.1 cells are not independent observations (the BIWI pair and the IAS
pair share byte-identical training windows and checkpoints; KGBD duplicate-safe
is a separate train set). The valid resampling unit is the independent training
run `(dataset family, backbone, seed)` = 4 families × 2 backbones × 5 seeds =
**40 clusters / 60 cells**.

- Script: `experiments/scale_content_controls/scripts/pooled_frame_stats_cluster.py`
  → `experiments/scale_content_controls/aggregate/pooled_frame_stats_cluster.md`.
  Reads `results/per_seed_frame.csv`, so point estimates match the frozen
  pooled numbers exactly.
- Method: cluster block bootstrap 95% percentile CI (100,000 draws, resampling
  the 40 clusters with replacement); cluster sign-flip permutation p (100,000
  draws, flipping every cell inside a cluster together, two-sided); cluster-mean
  one-sample t-test p (df = 39).
- Results: absolute +0.83 (CI [+0.54, +1.16], perm p < 0.0001, t p < 0.0001);
  normalized +0.16 (CI [−0.09, +0.42], perm p 0.266, t p 0.432);
  norm_matched +0.01 (CI [−0.28, +0.29], perm p 0.946, t p 0.650);
  random_matched +0.06 (CI [−0.20, +0.34], perm p 0.678, t p 0.893).
  Cross-arm: abs−norm +0.68 (CI [+0.53, +0.83]); abs−normmatch +0.82
  (CI [+0.54, +1.11]); abs−random +0.77 (CI [+0.63, +0.93]); all three
  cluster permutation p < 0.0001.
- Arm × backbone interaction (P2-3): `.../scripts/arm_backbone_interaction.py`
  → `.../aggregate/interaction_summary.md`. Null interaction (F = 0.31,
  p = 0.82; permutation p = 0.22), reported descriptively in the manuscript
  §4.5.1.
- `figures/fig1_forest_pooled.png` is regenerated by `scripts/make_p2_figures.py`
  using the cluster bootstrap CI.

## Deterministic Laplacian positional encoding (P1-3)

- The Laplacian positional encoding is computed deterministically: the
  eigendecomposition always runs on CPU (fixed LAPACK basis inside the
  near-degenerate eigenspaces caused by symmetric skeleton limbs) plus a
  per-eigenvector sign-canonicalization (largest-magnitude entry positive).
  CPU vs GPU now produce byte-identical PE (max abs diff 0.0).
- Location: `frame_isrt/transg_faithful.py` (`_laplacian_pos_enc`).
- Re-verification under the fixed PE: `experiments/pe_determinism/`.

- `frame_isrt/model.py` — Frame backbone + residual architecture
  (`IdentityScaleResidualGRU`, `IdentityScaleResidualSequence`, `build_mva_model`).

  ST-GCN, and the auditable `TranSGPyTorchReproduction`.
- `frame_isrt/transg_faithful.py` — faithful TranSG port with the deterministic
  Laplacian-PE sign rule.

  `config.json` writes.
- `scripts/frozen_matrix.py`, `scripts/export_per_seed_results.py`,
  `scripts/make_p2_figures.py`, `scripts/train_transg_faithful.py`.
